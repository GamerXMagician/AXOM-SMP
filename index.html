How to Join

  • 1
    Open Minecraft Java Edition

    Launch the game and go to the main menu.

  • 2
    Select Multiplayer

    Choose the Multiplayer option from the main menu.

  • 3
    Click Add Server

    Open the server list and add a new server entry.

  • 4
    Enter the address

    Type axomsmp.ice.lol as the server address.

  • 5
    Apply for whitelist

    Submit an application below.

  • 6
    Wait for approval

    Our team reviews applications — you'll hear back on Discord.

  • 7
    Join AXOM SMP

    Once whitelisted, connect and start playing!
